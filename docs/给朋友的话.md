## 这是什么

一个**常驻在桌面右上角的小面板**，用来记住「我看到过、但以后要处理」的事情。

它跟普通待办软件最大的不同有两处：

**一、你只需要截一张图，不用打字。**
看到一段聊天、一篇文章、一个订单、一个视频，按快捷键框一下就存进去了。
不用写标题、不用填日期、不用选分类——**你只要回答一个问题：这是「必须做」还是「想做」**。

**二、它有「两个房间」，而且管法完全相反。**

| | Todo | Wantdo |
|---|---|---|
| 是什么 | 有期限的活（作业、工作） | 没期限的愿望（想看的、想学的） |
| 会怎样 | 永远不变，只会逾期 | **你不碰它，它就慢慢变淡**，三周后滑进纸篓 |
| 但 | | 纸篓里的随时能捞回来，而且是满血复活 |

「想做」的东西会自己变淡，是故意的：**你的注意力有限，淡掉的那些说明你其实没那么想要它。** 这不是失败，是筛选。

## 怎么用

### 1. 打开

- 双击 `RemeberEr-0.5.0-portable.exe`（**免安装**，放哪都行）
- 桌面**右上角**会出现一个白色小面板
- 关掉：点面板右上角 ✕，或按 `Ctrl + Shift + Q`

### 2. 想先看它长什么样

面板上点 **⚙** → 「**灌入演示数据**」→ 回到主界面。

然后点右上角 **⚡** 打开演示加速——**时间被压缩 6000 倍**（1 天 ≈ 14 秒）。
等 1~2 分钟，你会看到「Wantdo」的卡片慢慢变淡；
再等几分钟，最旧的那张会自己滑进「Paper Plane Bin」。

> 演示加速只是临时开关，关掉就恢复正常速度了。

### 3. 真正用起来

| 操作 | 说明 |
|---|---|
| `Ctrl + Shift + A` | **截图**（主入口）。屏幕变暗后拖一个框，松手会让你选 Todo / Wantdo |
| `Ctrl + Shift + H` | 显示 / 隐藏面板 |
| `Ctrl + Shift + Q` | 退出 |
| 点 Todo 那一条 | 打开详情，可以改标题、写备注 |
| **在一条上停半秒** | 左边会弹出放大预览——不点进去就能看清图里记了什么 |
| 勾掉 Todo | 变成已完成（还能反悔）；**再点它一下**，它会像泡泡一样消失，进完成列表 |
| 点 Wantdo 卡片 | 打开详情 → **Get Done** 会让你写一句心得，然后归档 |

### 4. 两个提醒

- **第一次开可能被 Windows 拦**：见下面
- **`Ctrl + Shift + A` 可能被别的软件占用**（微信、QQ、各种截图工具都爱用）。
  如果按了没反应，就是想截图的软件抢走了；先用面板上的 **✂** 按钮代替，或者告诉我，我改成别的键

## ⚠️ 第一次打开被拦住了怎么办

这个程序**没有买代码签名证书**（个人项目，一年好几百刀），所以 Windows 会拦一下。这不是病毒，是我自己写的。

**表现**：双击后弹出蓝框「Windows 已保护你的电脑」

**解决**：
1. 点框里的「**更多信息**」
2. 点出现的「**仍要运行**」

（如果被 SmartScreen 直接删掉了，去 `Windows 安全中心 → 病毒和威胁防护 → 保护历史记录` 里把它「允许」恢复。）

**另外**：如果杀毒软件报毒，也大概率是误报。原因是这个程序会
① 注册全局快捷键 ② 截屏 ③ 调用系统的 PowerShell 去读取"当前窗口叫什么名字"。
这三件事单独都很正常，但**凑在一个没有签名的 exe 里**，很容易触发启发式规则。

要是你介意，就别装——完全理解。

## 我不确定的地方（特别想听你的反馈）

1. **「想做的东西会变淡」这个机制，你觉得是「被解放」还是「被冒犯」？**
   这是整个设计里我最没底的一点。它是核心，也可能是最让人不舒服的地方。

2. **按 `Ctrl + Shift + A` 之后，到屏幕变暗，你感觉有延迟吗？**
   我这边测出来大约 0.8 秒（Snipaste 那种是 0.05 秒量级），想知道在你机器上体感如何。

3. **弹出来的那个小卡片，你会不会嫌它打断你？**

4. **有没有哪些你截图存下来的东西，其实根本不想让它出现在这里？**

## 数据在哪 / 怎么删

所有东西（截图原图 + 数据）都只存在你自己的电脑上：

```
%APPDATA%\RemeberEr\
```

**不联网、不上传、没有账号**。想彻底删掉：退出程序，把这个文件夹删掉，再把 exe 删掉就行了。
