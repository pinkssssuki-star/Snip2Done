# 打包说明（发给朋友 / 以后发版本）

## 一条命令

```powershell
cd "D:\Users\Yint\Documents\ab_doc\做点小项目\remeber-er"
npm run dist
```

它会做三件事：

1. `node scripts/make-icon.js` —— 用代码画出 `build/icon.png` 和 `build/icon.ico`（**图标是生成的，不用手动准备图片**）
2. `electron-builder --win --x64` —— 打包
3. 产物落在 `dist\`

## 产物是什么

| 文件 | 用途 |
|---|---|
| `dist\RemeberEr-0.5.0-portable.exe` | **发给朋友用这个**。单文件、免安装、双击就跑 |
| `dist\RemeberEr-0.5.0-win-x64.zip` | 解压即用版。如果朋友那边 exe 被杀软直接删掉，用这个更保险 |
| `dist\win-unpacked\` | 没压缩的原始目录，调试打包问题时看它 |

> `portable.exe` 每次运行都会把程序解压到临时目录再启动，所以**第一次启动会慢几秒**，
> 而且启动后临时目录里会有一份。zip 版没这个问题。**两个都发过去让朋友自己选。**

## 发之前建议做的检查

1. **在本机先跑一遍 portable.exe**——确认不是"开发能跑、打包就白屏"
2. 打开后点 **⚙ → 灌入演示数据**，确认能出画面
3. 按一次 `Ctrl+Shift+A`，确认框选、选择器、入库都正常
4. 确认 `%APPDATA%\RemeberEr` 里生成了 `data.json` 和截图

## 两个必须提前知道的坑

### 0. 第一次打包会卡在 `winCodeSign` 解压（**我已经替你解决了**）

**症状**：

```
⨯ cannot execute  cause=exit status 2
  Extracting archive: .eb-cache\winCodeSign\xxxxx.7z
  Sub items Errors: 2
```

**原因**：`winCodeSign-2.6.0.7z` 里有几个 macOS 用的**符号链接**，Windows 在没有开「开发者模式」时不允许创建符号链接，于是 7-Zip 解压报 2 个错误、退出码 2，electron-builder 就直接中止了。

**它只用于代码签名，对 Windows 打包毫无用处**（关键文件 `rcedit-x64.exe` 其实已经解出来了）。

**我已经做的事**：把解压出来的内容补成了它期望的目录名，所以缓存现在是完整的：

```
.eb-cache\winCodeSign\winCodeSign-2.6.0\
```

**你现在直接 `npm run dist` 就能成功**（第二次跑会跳过下载，快很多）。

**换电脑 / 清过缓存后**，两种解法任选：

```powershell
# 解法一：开 Windows 开发者模式（设置 → 系统 → 开发者选项），然后重跑
# 解法二：把 .eb-cache 整个目录拷过去（最省事，直接复用我这份缓存）
```

> 顺带一提：`dist\win-unpacked\` 里的东西其实已经打好了，即使安装包这一步失败，
> 你也可以自己压缩它发出去 —— `Compress-Archive dist\win-unpacked\* RemeberEr.zip`
> 这就是一个能解压即用的版本。

### 1. 没有代码签名 → 朋友会被拦

个人项目没有代码签名证书（一年几百刀），所以：

- 双击后 Windows 会弹蓝框「Windows 已保护你的电脑」
- 朋友需要点「更多信息」→「仍要运行」

**`给朋友的话.md` 里已经写清楚了这一段，直接一起发过去。**

### 2. 杀软误报概率不低

这个程序会做三件容易被误判的事：

| 行为 | 为什么需要 | 为什么会被误判 |
|---|---|---|
| 注册全局快捷键 | 快捷键截图 | 键盘钩子的常见特征 |
| 截取屏幕 | 核心功能 | 截屏行为 |
| **调用 PowerShell** | 读取「当前窗口叫什么名字」 | **这条最可疑** |

第三条值得单独说：读窗口标题本来只需要一次 Win32 调用，但 Electron 没有原生接口，
所以只能起 `powershell.exe` 跑一小段 C#。**这个行为模式（无签名 exe → 起 PowerShell）非常像恶意软件。**

真要发出去给很多人用，长远看应该：
- 用 Rust/C++ 写个极小的原生模块替掉 PowerShell（**顺便解决那 400ms 延迟**）
- 或者买签名证书

**现在这个阶段：让朋友加白名单，或者用 zip 版。**

## 简化版：如果打不出来怎么办

electron-builder 首次运行要下载 Electron（158MB）+ NSIS + winCodeSign，
在国内可能很慢或失败。加两个环境变量走镜像：

```powershell
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
npm run dist
```

首次完整打包实测：**约 2 分钟**（Electron 下载占 50 秒）。之后会走缓存，快得多。

如果连 electron-builder 都装不上，还有个**土办法**（不需要任何打包工具）：

```powershell
# 把 dist\win-unpacked\ 整个目录压缩发过去就行
Compress-Archive -Path dist\win-unpacked\* -DestinationPath RemeberEr.zip
```

`win-unpacked` 是 electron-builder 已经组装好的完整可运行目录（含 Electron 运行时），
解压双击里面的 `RemeberEr.exe` 就能跑。**体积 100MB 左右，但一定是能用的。**

## 使用说明（给朋友的那份）

```powershell
npm run guide
```

生成 `给朋友的话.html` —— **单文件、离线可看**，截图和图标都 base64 内联进去了，
朋友双击用浏览器打开就行，不需要联网、不需要别的文件。

它依赖 `.guide\` 里的截图（由开发场景钩子抓的）。**界面改过之后想更新说明里的图**，重抓一遍再生成：

```powershell
# 抓图（会输出到 .guide\）
$env:REMEBER_USER_DATA = "$PWD\.userdata-guide"
$env:REMEBER_SEED = "1"
$env:REMEBER_DEV_SCENE = "all"
$env:REMEBER_CAPTURE_PANEL = "$PWD\.guide\shot.png"
npm run demo
# 然后重新生成
npm run guide
```

同时还有一份纯文本版 `给朋友的话.txt`（HTML 打不开时的兜底）。
