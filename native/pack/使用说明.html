记忆面板

一个常驻桌面角落的小面板。
看到以后要处理的东西，按 Ctrl+Shift+A 截下来，
做一次判断 —— 这是 Todo 还是 Wantdo —— 然后它就一直挂在你桌面上。

怎么开始

双击「记忆面板.exe」就行。不用安装，不用装任何东西。

第一次打开是空的。想先看看它长什么样，点右上角 ⚙ → 「灌入演示数据」，会给你塞几条样例。然后点右上角的 ⚡（演示加速），等一两分钟，能看着 Wantdo 磁贴慢慢变淡、最后掉进纸篓 —— 真实节奏是 7 天 / 21 天，那个按钮只是把时间压缩了 6000 倍给你看。

只记两个热键就够

Ctrl+Shift+A
截图（主要入口）
Ctrl+Shift+H
显示 / 隐藏面板
Ctrl+Shift+Q
退出

截图之后：

  1. 屏幕会暗下来，拖动鼠标框选你想记住的那块
  2. 松手以后框还在，可以拖角微调、拖框里面平移
  3. 点框外面右下角那个黑底白勾（或者按 Enter）确认
  4. 弹出三个按钮：Today（一天内）/ Soon（三天内）/ Wantdo（无期限）—— 选一个，它就去对应的房间了

嫌第三步多余？设置里打开「快速模式」：一框，一分类。

几个藏起来的操作

  • 点一下 Wantdo 磁贴 = 看它一眼 = 续命（生命条会回满）
  • 在一个条目上停半秒，左边会弹出放大预览，不用点进去就能看清
  • 勾掉 Todo 只是标记完成，它还留在原地让你能反悔；再点一下整行，它会「化掉」收进完成列表
  • 完成记录里会记着你用了多久、看过几次、写了多少字的心得
  • 按 ✕ 不是删除，是「暂时放下」，进 Paper Plane Bin，随时能捡回来

顶栏那几个按钮：

⇧
窗口置顶开关。嫌它一直压在最上面挡事，点一下关掉
▾
折叠成一条，只留顶栏
⚙
设置（透明度、Wantdo 保护期、多久后放手、快速模式）
只有一块屏的话：把面板往屏幕边缘外面拖，松手它就会贴边藏起来，只留一条窄边和一个紫色小条。鼠标移上去滑出来，移开再滑回去。不占位置，也不用关掉它。

可能遇到的问题

  • 第一次运行 Windows 可能弹「已保护你的电脑」。点「更多信息」→「仍要运行」。这是因为程序没有买代码签名证书，不是因为它有问题 —— 一共就一个 170 KB 的 exe，没有网络请求、没有模型调用、不收集任何东西。
  • 杀毒软件可能报可疑。也是同一个原因：这个程序会注册全局热键、会截屏，这类行为容易触发启发式规则。
  • 只支持 Windows 10 / 11。需要 .NET Framework 4.8（系统自带，不用装）。
  • 任务栏里不会出现图标 —— 面板是设计成常驻桌面角落的。想找它按 Ctrl+Shift+H，退出按 Ctrl+Shift+Q 或顶栏的 ✕。

你的数据在哪

%APPDATA%\remeber-er\ —— 在资源管理器地址栏粘贴这行就能打开。

里面是 data.json + 一个 images 文件夹，全是明文和普通 PNG。想从干净状态重来，直接把这个文件夹删掉。卸载 = 删掉 exe + 删掉这个文件夹。
